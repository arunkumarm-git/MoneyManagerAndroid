Financial data is personal. Money Manager guarantees your financial records never leave your physical device.

Quickstart

How to Install & Build

Get the app running on your Android device in under 2 minutes.

01

Direct APK Installation

Download the debug build directly and install it on your Android 8.0+ smartphone.

Download APK from GitHub Releases Target: Android SDK 34 • Min: Android 8.0 (API 26)
02

Build from Source

Clone the repository and compile using the Gradle wrapper with JDK 17:

Terminal / PowerShell 
git clone https://github.com/arunkumarm-git/MoneyManagerAndroid.git
cd MoneyManagerAndroid
./gradlew assembleDebug
03

Deploy Wirelessly via ADB

Enable Wireless Debugging in Android Developer Options and deploy straight from your laptop:

Terminal / ADB 
adb pair <PHONE_IP>:<PAIRING_PORT>
adb connect <PHONE_IP>:<PORT>
./gradlew installDebug
